# Lego Flow Terminals — VT400

VT400 terminal emulator with workstation capabilities.

## Features

- All VT200 features (inherited)
- Extended SGR codes (82–89 foreground, 92–99 background)
- Multiple window support (2 windows)
- Scroll history buffer
- Window selection (CSI n t)

## Compatibility

- **DEC VT400/VT420** — workstation terminals with window support
