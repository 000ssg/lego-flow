# Lego Flow Terminals — VT200

VT200 terminal emulator with video reverse and function key support.

## Features

- All VT100 features (inherited)
- SGR code 52 (video reverse) and 55 (video normal)
- Function key support (PF1–PF3, PL1–PL6)

## Compatibility

- **DEC VT200** — extends VT100 with mechanical terminal capabilities
- Video reverse mode for display inversion
