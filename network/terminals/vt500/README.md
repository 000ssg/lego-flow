# Lego Flow Terminals — VT500

VT500 terminal emulator with advanced character set support.

## Features

- All VT400 features (inherited)
- DEC character set selection (SO/SI)
- G0/G1 character sets (ASCII, DEC Special, UK, French, German, etc.)
- User-defined character sets via DCS
- Window host commands
- Alternate screen (DECSET 1049)

## Compatibility

- **DEC VT500/VT510/VT520** — advanced workstation terminals
- DEC Special Character and Line Drawing Set
- International character sets (UK, French, French-Canadian, German, Scandinavian)
