# SSH Tests — Checkpoint (2026-08-21)

## Phase 1: SSH — FIXED & PASSING

### Decisions Made
1. **ChaCha20-Poly1305 nonce direction**: Always `direction=0`. The two-key scheme (k0/k1) already provides key separation. `encrypting` flag only selects key set, not nonce direction.
2. **CommandFactory interface**: No `throws IOException` — must wrap all stream writes in try-catch.
3. **SshServerConfig.Builder**: Only supports `preferredCiphers` and `preferredMacs` — no KEX or host key setters.
4. **SSH key for Docker auth**: `/tmp/legoflow-test` ed25519 key; Docker SSHD container has `authorized_keys` populated.
5. **OpenSSH client for subprocess tests**: Uses system `/usr/bin/ssh` with `-o StrictHostKeyChecking=no` and `-o UserKnownHostsFile=/dev/null`.
6. **Embedded test user**: `interopuser`/`interotp` for SSH server/client interop.
7. **Standardized CipherList**: chacha20-poly1305@openssh.com, aes256-ctr, aes128-ctr, aes256-gcm@openssh.com, aes128-gcm@openssh.com.
8. **Standardized MacList**: hmac-sha2-512-etm@openssh.com, hmac-sha2-256-etm@openssh.com, hmac-sha2-512, hmac-sha2-256.
9. **KEX algorithms to test**: curve25519-sha256, ecdh-sha2-nistp256, diffie-hellman-group14-sha256, diffie-hellman-group16-sha512.
10. **Host key algorithms to test**: ssh-ed25519, ecdsa-sha2-nistp256, rsa-sha2-512, rsa-sha2-256.
11. **MAC algorithms to test**: hmac-sha2-256-etm@openssh.com, hmac-sha2-256, hmac-sha2-512.

### Bugs Fixed
1. **makeCommandFactory() missing braces**: if-else chain had no closing braces — rewrote as proper if-else-if-else.
2. **Order(9) test missing closing brace**: try-with-resources test at Order 9 was missing `}` to close catch block — inserted `}` after catch body.
3. **CommandFactory stderr write**: stderr.write() in catch block threw IOException uncaught — wrapped in inner try-catch.
