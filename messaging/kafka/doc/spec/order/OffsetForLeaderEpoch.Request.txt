OffsetForLeaderEpoch Request — field processing order (binding; spec 3.6.1) — flexible encoding from v4
wire order by layout (equal run = byte-identical field layout):
  v0-v3: ClusterId:Topics[]

field lines (fixed-width, no flexible encoding):
  v0-v3: ClusterId:string
  v0-v3: Topics:[]struct{TopicName:string,PartitionIndexes[]int32}

  v4: ClusterId:Topics[]

field lines (flexible encoding, KIP-482):
  v4: ClusterId:compact_string
  v4: Topics:[]struct{TopicName:compact_string,PartitionIndexes[]int32}

notes:
  - Flexible encoding from v4 (KIP-482)
  - compact_string = varint(N+1) + bytes
  - array counts are varint
  - endTags = varint(0) for each element with no tags
